From transaction to signal

  1. Validate & lock

    Validate integer paise and lock the account row to serialize concurrent requests.

  2. Extract behavior

    Compare amount, device, country, account age, and recent transaction velocity.

  3. Run inference

    A worker thread evaluates an eight-feature neural network.

  4. Store & broadcast

    Commit to PostgreSQL, then send a live dashboard event.

  5. Review the signal

    An analyst records a decision and a note in the audit history.

Risk indicators describe observed conditions; they are not neural-network feature attributions. No payments are actually blocked.
